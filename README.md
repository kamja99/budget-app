# 가계부 (budget-app)

개인·교회 가계부를 한 화면에서 관리하는 단일 HTML 웹 앱입니다.

- **개인 가계부**: 급여 기간(월급날~다음 월급날) 기준 달력·내역·통계, 자산·카드 잔액 관리
- **교회 가계부**: 부서 예산 항목(간식비·교재비·다과비 등) 수입·지출 기록
- **장부 추가/전환/이름·아이콘 수정**, 카테고리 관리, 이체·카드대금 처리, PC·모바일 반응형
  장부 목록에서 이름 옆 ✎을 누르면 **이름과 아이콘을 한 창에서** 바꿀 수 있습니다.
  아이콘은 32개 그리드에서 고르거나 이모지·한 글자를 직접 넣을 수 있고, 미리보기 배지로 확인한 뒤
  저장하면 상단 헤더와 장부 목록에 바로 바뀌고(새로고침 뒤에도 유지) 구글 시트 `장부목록` 탭에도 함께 저장됩니다
- **자산 뱃지**: 통장·카드마다 아이콘과 뱃지 색을 직접 골라 목록에서 한눈에 구분
- **변동 자산 추이**: 증권·연금처럼 매일 평가금액이 바뀌는 계좌는 날짜별 평가금액을 적으면
  꺾은선 그래프로 추이를 보고, 가장 최근 평가금액이 그 계좌의 현재 잔액이 됩니다
- **주간 추이 그래프**: 통계 탭에서 최근 8주(월~일) 지출을 막대그래프로 비교합니다.
  `생활비 전체`는 생활비 카테고리 지출만 세고(생활비 카드와 같은 기준) 주간 예산 기준선을 점선으로 함께 그립니다.
  다른 카테고리 칩을 누르면 그 카테고리의 주간 추이로 바뀌고, 막대를 누르거나 마우스를 올리면 그 주의 날짜·금액·전주 대비 증감이 나옵니다
- **뒤로가기로 닫기**: 모달·바텀시트가 열린 상태에서 안드로이드 뒤로가기를 누르면
  앱을 나가지 않고 맨 위 창만 닫힙니다 (통계·자산 탭에서는 달력으로 돌아옵니다)
- **카테고리 관리**: 장부 메뉴 → **카테고리 관리**에서 지출·수입 대분류를 직접 추가하고
  이름·아이콘·색·순서(▲▼)를 바꾸거나 삭제할 수 있습니다. 카테고리를 누르면 그 안의
  세부 카테고리도 추가·이름/아이콘 수정·삭제할 수 있고, 이름을 바꾸면 그 이름으로 적힌 내역도 함께 바뀝니다
- **세부 카테고리 비중(%)**: 통계 탭에서 카테고리를 누르면 세부 항목별 비중 표
  (`전체 100%` 헤더 + 항목별 %·금액)가 먼저 나오고, 세부 항목을 누르면 아래 내역이 그 항목만으로 걸러집니다
- **세부 분류(선택)**: 카테고리 아래에 `커피`·`군것질` 같은 하위 분류를 두고 일별 내역·통계에서 나눠 보기
- **생활비 예산 주별·월별**: 메인 생활비 카드의 톱니(⚙)에서 기준을 **주별(월~일)** 또는 **월별**로 고릅니다.
  월별은 **매월 1일~말일**, **월급 기간**(급여일·직전 영업일 계산), **매월 직접 지정**(매월 N일~다음 달 그 전날) 중에서
  기간을 고를 수 있고, 고른 기간의 실제 날짜와 그 기간 지출 합계로 남은 예산·사용률을 계산합니다.
  합계에는 **`🎈 생활비` 카테고리 지출만** 들어갑니다(`👊 생활비 외 지출`·`📌 고정지출`·`✔️ 경조사`·`🍱 점심비`·`잔액수정`·이체는 제외).
  카테고리 관리에서 생활비 이름을 바꾸면 그 새 이름을 그대로 따라가고, 설정은 `설정` 탭 키/값(`budget_mode`, `month_budget`, `budget_month_type`, `budget_month_start_day`, `living_cat`)으로 동기화됩니다
- **구글 시트 연동(선택)**: Google Apps Script 웹 앱을 연결하면 내역·자산·설정을 시트와 주고받습니다

## 쓰는 법

`index.html` 하나로 동작합니다. 인터넷 주소로 열거나 파일을 내려받아 브라우저로 열면 되고,
입력한 내역은 그 브라우저의 localStorage에 저장됩니다. 시트 연동을 켜지 않는 한
외부로 전송되는 데이터는 없습니다.

앱은 **빈 상태**로 시작합니다. **자산·카드** 화면에서 통장·카드를 먼저 추가하면
내역을 기록할 수 있습니다(현금·은행·카드·저축·투자·보험 6개 구분).

개인 가계부의 기본 지출 카테고리는 `🎈 생활비`(기타·커피·군것질·장보기·식비),
`👊 생활비 외 지출`, `📌 고정지출`(티머니·유튜브·넷플·티빙), `✔️ 경조사`, `🍱 점심비`로 시작합니다.
언제든 **카테고리 관리**에서 바꿀 수 있고, 이미 내역이 있는 카테고리 이름은 그대로 유지됩니다.

## 구글 시트 연동

1. 구글 시트에서 **확장 프로그램 → Apps Script**를 열고, 안내받은 Apps Script 코드를 붙여넣습니다.
   코드 위쪽 `SECRET_TOKEN`에 원하는 PIN을 넣습니다.
2. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자)으로 배포하고 나온 URL(`…/exec`)을 복사합니다.
3. 앱에서 **장부 이름을 눌러 → 구글 시트 연동**에 URL과 같은 PIN을 넣고 **연결 테스트 및 불러오기**를 누릅니다.

연결하면 앱을 열 때 시트의 최신 값을 불러오고, 내역·자산·설정이 바뀔 때마다 시트에 반영합니다.
카테고리 구성(이름·아이콘·색·순서·세부 카테고리)은 `설정` 탭의 `cat_config`(JSON) 한 칸으로 오가므로
Apps Script 를 고치거나 다시 배포하지 않아도 기기 사이에 그대로 유지됩니다.
웹 앱 URL과 PIN은 그 브라우저의 localStorage에만 저장되며 코드나 저장소에는 들어가지 않습니다.
