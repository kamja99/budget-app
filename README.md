# 가계부 (budget-app)

개인·교회 가계부를 한 화면에서 관리하는 단일 HTML 웹 앱입니다.

- **개인 가계부**: 급여 기간(월급날~다음 월급날) 기준 달력·내역·통계, 자산·카드 잔액 관리
- **교회 가계부**: 부서 예산 항목(간식비·교재비·다과비 등) 수입·지출 기록
- 장부 추가/전환/**이름 수정**, 카테고리 관리, 이체·카드대금 처리, PC·모바일 반응형
- **세부 분류(선택)**: 카테고리 아래에 `커피`·`군것질` 같은 하위 분류를 두고 일별 내역·통계에서 나눠 보기
- **구글 시트 연동(선택)**: Google Apps Script 웹 앱을 연결하면 내역·자산·설정을 시트와 주고받습니다

## 쓰는 법

`index.html` 하나로 동작합니다. 인터넷 주소로 열거나 파일을 내려받아 브라우저로 열면 되고,
입력한 내역은 그 브라우저의 localStorage에 저장됩니다. 시트 연동을 켜지 않는 한
외부로 전송되는 데이터는 없습니다.

앱은 **빈 상태**로 시작합니다. **자산·카드** 화면에서 통장·카드를 먼저 추가하면
내역을 기록할 수 있습니다(현금·은행·카드·저축·투자·보험 6개 구분).

## 구글 시트 연동

1. 구글 시트에서 **확장 프로그램 → Apps Script**를 열고, 안내받은 Apps Script 코드를 붙여넣습니다.
   코드 위쪽 `SECRET_TOKEN`에 원하는 PIN을 넣습니다.
2. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자)으로 배포하고 나온 URL(`…/exec`)을 복사합니다.
3. 앱에서 **장부 이름을 눌러 → 구글 시트 연동**에 URL과 같은 PIN을 넣고 **연결 테스트 및 불러오기**를 누릅니다.

연결하면 앱을 열 때 시트의 최신 값을 불러오고, 내역·자산·설정이 바뀔 때마다 시트에 반영합니다.
웹 앱 URL과 PIN은 그 브라우저의 localStorage에만 저장되며 코드나 저장소에는 들어가지 않습니다.
