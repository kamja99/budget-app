연결하면 앱을 열 때 시트의 최신 내역을 불러오고, 내역·자산이 바뀔 때마다 시트에 바로 반영해요.

장부별 시트

장부마다 다른 구글 시트를 연결할 수 있어요. 전용 시트를 연결한 장부는 그 시트로만 오가고, 연결하지 않은 장부는 위의 기본 시트에 함께 저장됩니다. 다른 사람 시트를 볼 때는 「불러오기만」을 골라 주세요.

처음 한 번: Apps Script 설치 방법
  1. 가계부 시트 → 확장 프로그램 → Apps Script
  2. apps-script-Code.gs 내용을 붙여넣고 SECRET_TOKEN에 원하는 PIN 입력
  3. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자
  4. 나온 URL(…/exec)과 같은 PIN을 위에 넣고 연결
